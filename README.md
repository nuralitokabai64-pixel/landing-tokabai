# landing-tokabai

**Тема:** Мастерская мебели (каталог, изготовление на заказ, контакты)  
**Живой сайт:** https://<ваш_логин_github>.github.io/landing-tokabai/

## Выполненные требования:
- **Семантические теги HTML5:** `header`, `nav`, `main`, `section`, `article`, `footer`.
- **Иерархия заголовков:** строго соблюдена цепочка `h1` → `h2` → `h3`.
- **Информационные блоки:**
  1. Шапка с навигацией по странице.
  2. Раздел «О нас».
  3. Блок «Каталог изделий» с качественными изображениями.
  4. Блок «Мебель на заказ» (преимущества и услуги).
  5. Форма обратной связи для расчёта заказа.
- **Доступность и SEO:**
  - Настроены поля `<label for="...">` для всех `input` и `textarea`.
  - Все поля формы отмечены атрибутом `required`.
  - Заполнены атрибуты `alt` для всех изображений.
  - Добавлены `title`, `meta description`, `meta viewport` и подключен `favicon`.
- **Адаптивный дизайн:** выполнен на чистом CSS3, корректно отображается на экранах от 375px до 1280px+.
